📜Results

Auto‑review criteria: Relevance score based on keyword/stem matches, morphological relations (prefixes/suffixes), relational phrases in definitions (e.g., "related to [category]"), strong phrases ("used for", "made of"), close spelling (edit distance scaled to word length), and domain tags. Scientific domains (biology, chemistry, physics…) are trusted, unless that same domain is in this category's own avoid list. Words scoring ≥2 are kept, ≤‑1 are rejected, others stay pending. Hover the ℹ️ icon to see the exact reason.

Magic and Royalty & Court are flagged as ambiguity-prone: auto-review can still auto-reject clear misses, but never auto-approves a "kept" for them — those are always left pending for a manual ✓, even with a high score.

🚀Push to GitHub & generate hints

Uploads the kept words as <category>-approved_words.json to your repo, then triggers the Generate Hints Actions workflow, which calls Gemini using the GEMINI_API_KEY stored in GitHub Secrets — that key never touches this page. The token below only needs repo contents + Actions write access, is used only to talk directly to api.github.com from your browser, and is kept solely in this browser's local storage.

Word gathering runs entirely in your browser against Datamuse's public, keyless API. The GitHub panel above is the only part of this page that sends data elsewhere — and only when you click its button.
